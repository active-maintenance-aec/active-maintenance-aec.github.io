Active maintenance

Active maintenance is the practice of updating a published paper’s replication code as the software around it changes, so that its results stay reproducible for years rather than months (Peer, Orr, and Coppock 2021). Each repository below holds the maintained version of one of my books or articles. It fetches the original replication deposit and checks every file against a checksum manifest, reproduces every printed number on current software, checks every claim in the text a second way, and publishes an itemized errata note whose corrections are computed by the code. A scheduled job reruns each one every eight weeks.

  • How we did it: the guide, written so that you can do the same for your own papers.
  • The scheduled check: maintenance, the shared workflow every repository calls.
